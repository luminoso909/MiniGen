## **一、任务包：待填写编号**

| 字段 | 内容 |
| --- | --- |
| 任务与状态 | 编号、目标、待做 / 进行中 / 已验证 / 受阻 |
| 角色、负责人、文件归属 | 单 Agent 或授权后的角色；互斥修改范围 |
| 依赖与输入 | 已通过依赖、配置、数据和接口版本 |
| 输出 | 文件、接口、记录位置 |
| 用户核心边界 | 哪些代码由用户完成，哪些工程可自主推进 |
| 假设与验收 | 预计行为、独立检查、验收命令与失败条件 |
| 实际执行 | 命令、设备、精度、种子、起止时间与退出码 |
| 证据与结论 | 日志、样本、指标、限制和未验证项 |
| 成本 | 实际费用、总累计和剩余预算 |
| 下一步 | 一个可执行动作及其依赖 |
