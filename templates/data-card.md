## **一、数据卡：待填写**

| 字段 | 内容 |
| --- | --- |
| 状态、数据版本、负责人 | 待做；不要填预期为实测 |
| 用途与能力边界 | 对应任务和不适用范围 |
| 上游来源与固定版本 | URL、revision 或归档哈希 |
| 许可与署名 | 许可链接、修改、再分享范围记录 |
| 获取与存储 | 实际命令、日期、数量、下载和占用 |
| 预处理与描述 | 尺寸、模式、背景、过滤、描述来源 |
| 划分与去重 | 种子、分组、完全及近似重复检查 |
| 字段与清单 | schema、哈希和数据根目录 |
| 质量与抽查 | 质量报告、样本、问题和修订 |
| 冻结与缓存 | 清单指纹、编码器和预处理版本 |
| 已知局限 | 偏差、缺失、不可推广结论 |
