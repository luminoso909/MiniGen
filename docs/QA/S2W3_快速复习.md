## 三者分工

**VAE（表示）**：RGB `x [B,3,128,128]` → 冻结编码器 → `h [B,4,16,16]` → `z₀=s*h`。最后逆缩放再解码。  
**DDPM（规则）**：对 `z₀` 随机采样 `t,ε`，构造 `zₜ=√ᾱₜ z₀+√(1−ᾱₜ) ε`；反向采样时多步更新潜变量。  
**DiT（预测）**：输入 `zₜ,t`，输出与 `zₜ` 同形的 `ε̂`，训练 `MSE(ε̂,ε)`。

## DiT 主干 Shape

```text
z_t [B,4,16,16] ── Patchify(p=2) ── [B,64,16] ── Linear(16→256) ──┐
                                                                       + position_2d(8,8,256) [1,64,256]
t [B] ── sincos_1d(256) ── Time MLP ── c(t) [B,256]                     │
                └──── 每个 Block 的 SiLU→Linear(256→1536) ──┐         │
                                                   gamma/beta/gate → DiTBlock ×6
                                                                         │
                                 Final LN + Final adaLN(c) ←───────────┘
                                             ↓
                                     Linear(256→16)
                                             ↓
                                       [B,64,16]
                                             ↓
                                         Unpatchify
                                             ↓
                                      ε_hat [B,4,16,16]
```

## 七个核心公式

1. `N=(H/p)(W/p)`，`K=C*p*p`，`patchify: [B,C,H,W] -> [B,N,K]`。
2. `PE_1D(v)=[cos(vω₀),...,cos(vωₘ₋₁),sin(vω₀),...,sin(vωₘ₋₁)]`，`ωₖ=10000^(-k/m)`。
3. `PE_2D(r,c)=[PE_1D(r,D/2); PE_1D(c,D/2)]`。
4. `adaLN(x,c)=(1+γ(c))*LN(x)+β(c)`，其中 `γ/β: [B,D] -> [B,1,D]`。
5. `x' = x + gate_attn * Attention((1+gamma_attn)*LN(x)+beta_attn)`；另一条残差分支将 Attention 换成 MLP。
6. `zₜ=√ᾱₜ z₀ + √(1−ᾱₜ) ε`，`ε ~ N(0,I)`。
7. `loss=((ε_hat-ε)**2).mean()`，与 `1/(BCHW)` 平均平方误差等价。

## 实验真实性

- 单元测试：检查各算子数值与形状。
- 分阶段梯度：零输出头先更新、再 Gate、再内部分支。
- 固定四样本拟合：只能证明优化链路和记忆能力，**不等于生成能力**。
