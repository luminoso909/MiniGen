### **1. 复习时优先补哪两项？**

- [ ] 手算 $2\times3$ Patch 网格的行、列坐标，用两个半宽的 SinCos 编码拼接，并检查展平后的顺序与 Patch 对齐。
- [ ] 手写 DiT 的位置编码注册：用 $H_p=H/p$、$W_p=W/p$ 作为网格大小，确认 `[1,N,D]` 能对 Batch 广播。理解 `persistent=False`：Buffer 会随模型迁移设备，省略于 `state_dict`。

<a id="q2"></a>

### **2. VAE、DDPM 和 DiT 分别做什么？**

- **VAE（图像表示）：** 冻结编码器把 RGB `[B,3,128,128]` 编码为近似后验，取均值 $h$（`[B,4,16,16]`），乘固定系数 $s=0.13025$ 得到 $z_0=sh$。生成的潜变量先除以 $s$，再用解码器生成 RGB。
- **DDPM（扩散过程）：** 训练时为每张图抽取时间步和独立标准高斯噪声，用闭式公式直接得到 $z_t$。生成时从高斯噪声出发，用反向采样器反复更新。
- **DiT（预测网络）：** 给定 $z_t,t$，输出与 $z_t$ 同形的噪声估计 $\hat\epsilon$，训练时和用于构造 $z_t$ 的同一份 $\epsilon$ 计算 MSE。

<a id="q3"></a>

### **3. DiT 主干的张量形状如何变化？**

```text
图像路径：
  z_t [B,4,16,16] → Patchify(p=2) [B,64,16] → Linear(16→256) [B,64,256]
    → 加位置编码 [1,64,256] → DiT Block ×6 [B,64,256]
    → Final LayerNorm + 条件调制 → Linear(256→16) [B,64,16]
    → Unpatchify → eps_hat [B,4,16,16]

时间路径：
  t [B] → SinCos1D [B,256] → Time MLP → c(t) [B,256]
    ├─ 每个 Block：SiLU → Linear(256→1536) → 两组 shift、scale、gate
    └─ 最终层：SiLU → Linear(256→512) → shift、scale
```

<a id="q4"></a>

### **4. 应该能写出哪些公式？**

1. **切块。** 设 $H,W$ 都可被块边长 $p$ 整除：$N=(H/p)(W/p)$，$K=Cp^2$。Patchify 将 `[B,C,H,W]` 重排为 `[B,N,K]`。
2. **一维位置或时间编码。** 宽度为 $2m$，令 $\omega_k=10000^{-k/m}$，$k=0,\ldots,m-1$。
   
   $$\operatorname{PE}_{1D}(v;2m)=[\cos(v\omega_0),\ldots,\cos(v\omega_{m-1}),\sin(v\omega_0),\ldots,\sin(v\omega_{m-1})]$$
3. **二维位置编码。** 隐藏宽度 $D$ 可被 4 整除时，拼接 Patch 行列坐标的两个半宽编码：$\operatorname{PE}_{2D}(r,c)=[\operatorname{PE}_{1D}(r;D/2);\operatorname{PE}_{1D}(c;D/2)]$。
4. **adaLN。** $\operatorname{adaLN}(X,c)=(1+\gamma(c))\odot\operatorname{LN}(X)+\beta(c)$。缩放与偏移从 `[B,D]` 扩为 `[B,1,D]` 后广播。
5. **两条残差支路。** MLP 接收已经完成注意力更新的 $X'$，两条支路各有独立的调制和门控。
   
   $$X'=X+g_a\odot\operatorname{Attention}(\operatorname{adaLN}_a(X,c))$$
   
   $$X''=X'+g_m\odot\operatorname{MLP}(\operatorname{adaLN}_m(X',c))$$
6. **加噪。** $z_t=\sqrt{\bar\alpha_t}z_0+\sqrt{1-\bar\alpha_t}\epsilon$，其中 $\epsilon\sim\mathcal N(0,I)$。
7. **Noise MSE。** $L=\frac1{BCHW}\sum_{b,c,h,w}(\hat\epsilon_{b,c,h,w}-\epsilon_{b,c,h,w})^2$，代码是 `((eps_hat - eps)**2).mean()`。

<a id="q5"></a>

### **5. 第三周的实验能说明什么？**

- 局部数值和形状测试检查切块、位置对齐、注意力及条件广播。完整教学模型零初始化后，输出头先收到梯度；输出头更新后，门控、再到内部支路可收到梯度。
- 固定四样本实验使用同一组图像、时间和噪声，MSE 从约 1.0015 降到 0.00181，验证这条优化链路能拟合固定监督。
- 六层主规格只做了前向检查；第三周没有随机时间训练、完整反向生成或生成质量评测。第四周的训练和生成应单独阅读。
