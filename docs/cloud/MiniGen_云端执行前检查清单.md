## **一、先审核，再运行**

本表是最终本地交接，不是已完成的云端验收。当前停在 **等待用户审核 Benchmark、实验配置和手册，随后由用户亲自开始 CUDA Pilot**。本轮没有租用 GPU、下载新大模型、启动正式训练或进入 P6。

先读 [Benchmark 最终审核包](../../reports/v2/benchmark/MiniGen_Benchmark_最终审核包.md)、[正式实验预登记](../../reports/v2/final/MiniGen_正式实验预登记.md)、[完整操作手册](MiniGen_云端训练与评测完整操作手册.md) 和 [最终工程摘要](../../reports/v2/final/P3_P4_P5工程最终验收摘要.md)。完整运行顺序继续维护在 [云端任务清单](云端任务清单.md)。

### **1. 用户现在需要决定的事项**

- [ ] 审阅 Benchmark 的数量/场景覆盖、重复问句、颜色绑定、组合题与验证语义近邻。决定发布修订版，或明确接受限定测量范围；当前候选不自动批准。
- [ ] 确认组合题仅称 composition_stress，不能称已验证 OOD；2,000 参考记录中有 1,999 个唯一图片/组，决定是否保留记录加权抽样。
- [ ] 审阅预登记的共同超参数、验证选择规则和单种子证据边界；正式步数、最终精度、学习率、EMA、GPU 和预算仍待 Pilot。
- [ ] 审阅手册并决定是否租用单卡 GPU、Pilot 费用上限和停止时间。本轮授权不等于自动云端开机授权。

Benchmark 未最终批准不阻止用户授权的 **训练/验证子集工程 Pilot**；会阻止正式 Test 生成、评分和正式实验定稿。当前 B0 16 图质量未过，也不阻止用于定位该问题的 Pilot；会阻止正式长训。

## **三、在云端逐项确认**

每次记录日期、命令、Git Commit、配置 SHA、设备型号、精度和结果路径；失败保留原因，缺测留空。

- [ ] `nvidia-smi`、持久化数据盘、Python/uv、锁定依赖、`minigen doctor --device cuda --json` 通过。Mac 上的成功不代替 Linux 首次安装。
- [ ] 固定源码 SHA 与本轮交付一致；`src/` 无临时未提交修改；远端已包含目标提交。
- [ ] 数据、清洗 Caption、分组、Manifest、组件 revision 与完整缓存同步。先 `--verify-only`，失败停止；不重建已批准的本机缓存。
- [ ] CPU/CUDA FP32 固定样本前反向对照；三模型各自检查，不能用 B0 通过替 B1/B2。
- [ ] BF16 支持检查、有限优化/EMA、显存/吞吐 Pilot，8 步连续与 4+4 恢复；不把 AMP 有限性写成 FP32↔AMP 数值等价。
- [ ] B0 单图诊断后，完整 16 图同初噪的正确/空/打乱条件对照；没有清晰主体/条件收益时停止长训，保存全部结果。
- [ ] 三模型各自 Pilot 后，以同有效 batch/共同 LR/EMA/日程填实预登记、预算和约 20 个快照；报价、评测和存储/传输成本单独记录。
- [ ] Benchmark 修订/限定范围的决定有版本和批准回执；正式训练前定稿，不因最终 Test 输出不好再换题。
- [ ] 用户明确批准 B0 长训，然后按既定质量关卡安排 B1/B2；不用本地 12 步检查点或 24 张指标冒充正式结果。
- [ ] 正式评测前在目标 CUDA 上验证独立 Inception/完整 CLIP/LPIPS，真实 BLIP 小批推理和 100+100 人工校准；不将 Mock 合入成绩。
- [ ] 配方选择只用 Validation。正式 Test 固定内容、种子、Checkpoint、采样设置，所有失败/未知/缺图保留分母与覆盖率。
- [ ] 训练、评测和恢复都使用独立输出目录；共享 run_id、Checkpoint/Benchmark/评测器哈希，不能只凭文件夹名称拼表。
- [ ] 备份 last.pt、快照、日志、配置、失败回执和评分原始记录到持久化盘；回迁 Mac 后比 SHA 并实际加载检查点，再释放实例。

## **四、当前无法替用户完成的验收**

真实 CUDA/AMP/驱动兼容性、GPU 吞吐/峰值显存、平台收费、正式质量、人类语义审核和校准均需要后续真实执行。多卡 DDP 尚未实现。单卡 FP32 采样与 BF16 训练是不同路径；强制中断只保证恢复到最后已发布的 Checkpoint；换 GPU 型号不能承诺逐位恢复。

本地复核复用可靠的 217 项回归证据，仅新增必要的定向测试和报告回放。详细结果见最终摘要；没有为通过状态而放宽质量或数值门槛。
