## **一、从第三周 Block 到第四周生成闭环**

任务对应 S2-04 至 S2-06。知识讲解与实际教学结果统一放在 [第四周 Notebook](../docs/learning/S2_第4周_潜空间扩散训练与采样.ipynb)，本文件只保留个人接手清单，不复制一份学习笔记或参考算法。

第四周教学分支显式使用第三周 Notebook 中唯一标记为 `dit_reference` 的单元，记录该单元源码哈希；噪声日程使用你已经实现并验收的 src DDPM。你的 VAE 作业和个人 DiT 仍按各自入口完成，不因教学分支运行而自动通过。

### **1. 先把整体数据流讲清楚**

画出两条分开的数据流，并在每条箭头旁标注形状与已知量：

1. 训练：`RGB [b,3,128,128] → 冻结 VAE 均值 → 缩放潜变量 [b,4,16,16] → 随机时间/噪声 → DiT 噪声预测 → MSE → 更新 DiT/EMA`。
2. 采样：`高斯噪声 [b,4,16,16] → 1000 次完整 DDPM 反向更新 → 逆缩放/VAE 解码 → RGB`。

训练时不解码每个 batch，VAE 参数也不接收梯度；生成时没有给定真实图像可供编码。重建图、固定监督拟合图、随机初始噪声的生成图是不同证据，不能混用。

## **二、第四周学习验收**

### **1. 需要你独立回答的问题**

1. 为什么加噪在潜空间进行，解码前却必须撤销 VAE 缩放？为什么不能凭观察到的标准差随意重归一化？
2. 固定时间、固定噪声的 100 步拟合通过，为什么仍不能证明随机时间训练或生成成功？
3. 全部时间混合的 MSE 下降时，为什么还要按时间分桶，并与零预测和高斯矩基线比较？
4. EMA 改变的是参数还是采样日程？参数平滑后损失一定更低吗？
5. 缓存部分完成时，哪些工作可以继续，哪些结论不能宣称？
6. 生成结果不理想时，如何依次排查 VAE 重建、训练尺度、时间覆盖、恢复身份与采样链？
7. 为什么直接跳过 DDPM 索引不等于 DDIM？本周为什么保留完整 1000 次更新？

参考推导、数值例子与答案在第四周 Notebook。个人验收要求你不看答案解释，并用本次真实指标支持判断；短训生成质量低也应保留失败样本。
