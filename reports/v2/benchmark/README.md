## **一、MiniGen-Bench ArtBench v1 候选冻结**

本版本将历史图标题型改为艺术绘画场景。正式主数据仍为 ArtBench Public Domain 256×256，未修改原始图像、Caption、分组或划分；P2 表示缓存未重建。

内容位于 [benchmark.json](artbench_v1/benchmark.json)，内容锁位于 [lock.json](artbench_v1/lock.json)。2026-11-10 的内容摘要为 `ff18ef2f5538538cf54411d4d4934e135bdd712c53d62247512825aaea4c62e5`。**内容已锁定，人工语义审核仍待完成**。程序能核验数量、字段和身份，但不能自行批准题目质量。协议同时绑定 `configs/models/evaluation.json` 与 `configs/benchmark/sampling_matrix.json` 的文件哈希，明确 KID/CMMD/CLIPScore 数学、VQA 四状态及保守分母、人工 1–5 分锚点。正式加载会再次检查绑定配置；小型测试 fixture 缺少资产绑定时不能获准正式执行。前一份未批准候选保留在 `artifacts/runs/p5_baseline/benchmark_candidate_previous/`，本轮 8+8 页面验证仍保留当时身份，不重跑伪造新记录。

### **1. 两套独立用途**

| 数据 | 数量 | 用途和限制 |
| --- | ---: | --- |
| 真实分布参考 | 2,000 | 从冻结 Test 4,619 张中固定抽样；正式 KID/CMMD 参考，按其 Caption 生成匹配数量的图片 |
| 主 Prompt 测试 | 160 | 80 ID + 40 组合压力 + 40 成对改写；每题固定两个初噪，共 320 图/模型 |

| 人工校准验证参考 | 100 | 提供未来正式校准的固定真实图索引；本轮只展示前 8 张及其 8 张退化副本 |

参考选择以 seed=20261110 和 sample_id 的规范 JSON SHA-256 排序，取前 N 个；不根据模型输出更换参考样本。图像路径、文件 SHA、group_id、来源 Caption 和 artist 都保留。训练/验证/测试的组与文件哈希交叉隔离检查通过；所选参考图片实际文件哈希通过。未使用测试图片训练或调参，没有执行正式 2,000 图生成或评分。

### **2. Prompt 定义和适用真值**

题目目录为 `configs/benchmark/prompt_catalog.json`。场景包括人物庭院、乡村和河流风景、海上船只、建筑、动物、静物与室内。主体、颜色、数量、属性绑定及空间关系要求保存在 `requirements`；这些表示 **Prompt 要求**，并不预先宣称生成图符合要求。

- ID：20 个主体场景，各四种请求。保留训练 Caption 的词匹配数量及最多五个样本 ID；本次所有主体都存在词证据，但未把它当成视觉标注。
- 组合压力：使用已见词汇构造不同对象的关系与属性组合。标记 `composition_stress`、`ood_verified=false`。**Caption 未出现不证明训练图片中未出现；没有真正 OOD 成功率。**
- Paraphrase：从 ID 的单数和双数题各取对应项，共 40 条；改写直接复用原题约束和语义族，与原题用相同初噪配对。
- 验证：独立 20 个主体场景，各四种请求。配置主体及题族标识与主测试分开；相关概念、上下位词与表达是否有语义近重复仍需人工审核，不能把 ID 检查宣称为完整语义隔离证明。

主测试初噪种子为 20261110、20261111；验证为 20261112、20261113。所有成对/逐架构比较使用相同 Prompt 和 seed。题目内容应先由用户审阅，再进行正式长训；若确需改题，发布新版本和新内容锁，不原地覆盖旧成绩的题目。

## **二、指标协议与失败口径**

正式 KID 默认 100 次抽样、每次 1,000 样本，报告均值和抽样标准差；CMMD 带宽 10、缩放 1,000；CLIPScore 使用 L/14@336、无文字前缀、权重 2.5 的显式变体。模型、预处理和实现版本另外绑定资产锁，不能把同名模型当作身份相同。

本地每模型少量生成图的分布指标仅属探索性，不能判断架构优劣。生成失败、不完整评分和不可判断问题全部保留；各属性只使用其适用分母，无关系要求的题不进入关系分母。VQA 本地 Mock 仅测试数据流，真实 BLIP 推理待云端；模拟结果不能混入真实评分表。

## **三、人工审核与校准材料**

已实际建立 **8 张验证图 + 8 张有谱系的退化图**，源图未改。退化为 GaussianBlur(radius=3)、64px 下采样后还原到 256px，不能称为模型生成结果。

网页在 `artifacts/evaluations/p5/calibration/review/review.html`；[小案例回执](calibration_smoke.json) 只记录材料准备完成。页面匿名化模型与文件名，内嵌图像，可按住放大、评分、标记错误、保存浏览器进度并导出/恢复 JSON。对应私有映射单独保存，不发送给盲评者。

本批校准题仅为 Caption 的总体主体/场景是否大体对应，用于验证工具；Caption 不是已审核真值。它 **不构成对象/颜色/数量/关系评分器的正式校准**。未来应使用按类别设计的问题和至少 100+100 张的独立真实人评，保留自动判断、人工判断、不可判和各类混淆。

本轮没有导入任何真实人工答案，没有生成假的一致率或模型盲评分数。HTML 中的脚本已通过 `node --check`；实际视觉检查范围在总验收报告另记。

## **四、批准与版本边界**

`load_benchmark(..., require_approved=True)` 额外要求独立的人工批准 JSON，包含匹配的 `benchmark_sha256`、`approved=true`、非空 `reviewer` 和 `reviewed_at`。程序不创建已批准回执；字段存在只用于工作流记录，不代表密码学身份认证。

交付时仍为 `pending_human_review`。需要用户确认的重点是绘画语义是否自然、数量和关系要求能否清晰判断、验证与主测试的近重复风险，以及组合题仅作为压力测试的解释。形式测试通过不能替代这一审核。
