## **一、固定数据身份**

2026-11-07，MiniGen 正式数据切换为 **ArtBench Public Domain 256x256**。源为 `alfredplpl/artbench-pd-256x256`，revision 为 `4056b70025f0e3f916fb271c7a792633ba637484`。从仓库的三个原生 Parquet 分片离线按批读取，1,517,381,098 字节均与上游分片 SHA-256 匹配。上游单一 `train` 有 **46,298 行**，本地独立计数一致。发布者称该版本选自 ArtBench 的公版作品，数据页标注 MIT。来源 URL 按行保留，作品和数字副本的逐项再分发权利待单独核对。[固定数据卡](https://huggingface.co/datasets/alfredplpl/artbench-pd-256x256/blob/4056b70025f0e3f916fb271c7a792633ba637484/README.md) · [原 ArtBench](https://github.com/liaopeiyuan/artbench) · [分片锁](../../../configs/datasets/artbench_pd_256.yaml)

## **二、图像与划分**

全量 46,298 张均可解码，全部为原生 **256×256 RGB JPEG**。图像直接使用上游 JPEG 字节，保留构图。解码失败、异常尺寸和近纯色图分别为 0。三个集合合计保留全部原始行。

| 划分 | 图像 |
| --- | ---: |
| 训练 | 37,042 |
| 验证 | 4,637 |
| 测试 | 4,619 |

按解码像素 SHA-256、规范化来源 URL 和近重候选分组。近重使用 64 位 dHash 距离至多 3，同时要求 4×4 RGB 缩略图的平均绝对差至多 12。以种子 `20261107` 哈希分组身份，目标为约 80/10/10。全量有 46,280 组，18 组各有两张图。精确像素重复行和同来源 URL 重复行各 15 条，两种规则可能重叠。另有 19 个未被精确规则预先归组的 dHash 候选对，其中 3 对达到颜色差门槛并归组。复验未发现组 ID、图像文件哈希、像素哈希或规范来源 URL 跨集合。近重规则覆盖阈值内的候选，强裁切、镜像与重绘仍可能漏检。[全量及复建回执](artbench_freeze.json)

以种子 `20261107` 从训练集合均匀随机抽查 240 张。三名代理目视检查原生比例预览及 Caption，个别难例另外查看 256px 原图。229 张未见明显技术性缺陷，11 张存在裁切边缘、极暗画面或网点等不确定项。未确认严重技术模糊、明显拉伸或技术性坏图。例如 `ab-15959` 的两侧人物头部在边缘被明显截断，当前副本无法区分构图与上游裁切。低对比和柔和笔触按作品表现判断。基于这些证据，图像适合直接进入 P2 的 256px 组件测试。[逐行观察](artbench_visual.json)

## **三、Caption 清洗与结果**

`artbench-caption-v1` 保留主体、场景、颜色、数量、空间关系和基本题材词。规则清理显式创作署名、年代、标题、纯艺术史句、重复及冗余开头，遇到与可见事实混写的句子优先保留视觉部分。清单保存原文、完整清洗版、最终训练版、操作列表与 token 数。使用锁定的 CLIP-B/32 tokenizer 验证 75 个内容 token 上限，超限依次在句、从句、词边界缩短并登记。全量原始 Caption 有 6,838 条超长，清洗后仍需缩短 4,974 条，均通过保留完整的前序句子处理。最终无空文本或超长文本，中位数 46，最长 75。[清洗实现](../../../src/minigen/data/artbench_caption.py) · [版本回执](artbench_freeze.json)

| 固定抽查的训练 Caption | 条数 |
| --- | ---: |
| 未见明显视觉事实错误 | 122 |
| 至少一处明确错误 | 71（29.6%） |
| 有细节难以判定 | 47 |

错误标签可重叠。以同一 240 条为观察范围，明确错误含主体 27、颜色 23、数量 13、关系与位置 24（原记录的 `relation` 与 `spatial`）、场景 17，另见姿态与媒介问题。该计数表示抽查中发现的错误，逐字段正确率需另定义可判定分母。例子包括 `ab-20004` 把两名婴儿写成持书和手杖的站立人物，`ab-25738` 为红白邮票补写藏蓝西装，`ab-13332` 将桌边三人写成两人，`ab-07531` 将岸边钟楼写成位于河中，`ab-25761` 把装饰文字页写成男子海报。部分署名和系列信息仍保留在混写句中。清洗无法验证或纠正上游的视觉事实，人工复核当前为 0。[逐行观察与错误标签](artbench_visual.json)
